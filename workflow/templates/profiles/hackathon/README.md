# Profile: hackathon / data app / anything with a deadline and a judge

For projects that end: a competition, a client demo, a portfolio piece. Adds a brief, a time budget, a judge pass and a freeze to the core workflow.

1. Copy `docs/*` from this folder into the project's `docs/` (this `plan.md` replaces the core one).
2. Add to the project's AGENTS.md:

```
## Milestones
Budget: [16] h of work. What each milestone must deliver: docs/plan.md.
M0 skeleton 5% · M1 foundation 15% · M2 core feature 25% · first-question check · M3 [extra layer] 10% · M4 polish 20% · judge pass + fixes 25% · freeze
- Log start and end times in a "Time" table in PROGRESS.md. When a milestone reaches its budget, stop and tell me what's left and what you'd cut; I decide.
- **After freeze:** bug fixes only; question any other change before doing it. For any change visible on screen, list the screenshots and clips that need retaking.
```

3. Add these rows to "Read only when needed":

```
| `docs/brief.md` | working on anything a user or judge sees; always for the judge skill |
| `docs/data.md` | before changing code that loads, joins or computes data |
| `docs/ai_log.md` | a new AI tool was used; writing the README or disclosures |
| `docs/PITCH.md` | only when I say "write the presentation materials" or "write the README" |
```

4. Reviews: the `judge` skill (sceptical judge, scores against "Judged on") instead of, or after, `review`.
